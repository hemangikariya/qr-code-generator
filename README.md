# 🚀 QR Code Generator

This project is a simple **QR Code Generator** built using **Python** and **PyQt5**.  
It allows users to generate QR codes from any text or URL.  
The application provides an easy-to-use graphical interface and the option to save the generated QR code as a PNG file.  

It’s a great tool for creating QR codes for websites, contact information, or any other data. 📱📧🌐

---

## ✨ Features

- 🔤 Generate QR codes for any URL or text  
- 💾 Save QR code as a PNG file  
- 🖥️ Simple and easy-to-use graphical interface  

---

## 🛠️ Technologies Used

- 🐍 Python  
- 🧱 PyQt5 *(for GUI)*  
- 🔲 qrcode *(for QR code generation)*  

---

## 🧩 Installation

```bash

```
2️⃣ Install dependencies
```bash

```
